# NZSL Web Application
A web application designed to help beginners learn New Zealand Sign Language (NZSL). The application follows a service-oriented architecture, consisting of a UI front-end for user interaction and a service back-end for handling requests and providing learning resources.

# Technology Used
C#, .NET, and EF Core – For backend development, API implementation, and database management
HTML, CSS, and JavaScript – For front-end development and user interface design
